# Field feedback

What reps ask and tell us. The Sales Enablement Lead agent logs here when it cannot fully answer a question in `/ask-enablement` or `/call-prep`, and when a rep shares feedback. On every launch run the agent reads this file and updates the objections and FAQ, then marks each entry as addressed.

Rules:
- This file shows what reps need. It is not proof. A rep's claim never becomes a customer-facing fact.
- No customer or person names. Log the question, not the call.
- Keep each entry to one line, newest first. Remove entries once they are addressed and the answer is in the enablement files.

Format: `- YYYY-MM-DD | <unanswered question | rep feedback> | <launch slug or "general"> | <text> | <open | addressed: file, section>`
